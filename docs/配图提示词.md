# 配图提示词表（LiblibAI / 水墨国风）

> 用途：给作品墙上的每首诗生成配图，替代现在的公版古画。
> 生成完的图按 **文件名** 存进 `_build/art/`，然后跑 `python tools/make-art-webp.py`
> 就会自动压成两档 WebP，直接可用。

---

## 一、LiblibAI 在线生图设置

| 项目 | 建议值 | 说明 |
|---|---|---|
| 基础模型 | 国风/SDXL 系底模 | 平台上搜「水墨」「国风」底模，选下载量高的 |
| **水墨 LoRA** | 权重 **0.7 ~ 0.9** | 太高会崩形，太低没效果；一批图必须用同一个 |
| 采样器 | DPM++ 2M Karras | SDXL 常用组合 |
| 迭代步数 | 25 ~ 30 | 再多收益很小 |
| **CFG** | **5 ~ 7** | 别调高！水墨风格 CFG 一高就发灰发僵 |
| 尺寸 | **832 × 1216**（竖幅） | 为竖排题款预留；别用横构图 |
| **种子 seed** | **固定一个值** | ⚠️ 最关键：不锁种子，11 首配图会像 11 个人画的 |
| 高清修复 | 可开，放大 1.5 倍 | 开了细节更实 |

**每首出 4~8 张，人工挑 1 张。** 挑图标准见文末。

推荐的社区 LoRA：
- [国画水墨风花卉](https://www.liblib.art/modelinfo/c0b85a556a1341009b43d9e404498289)
- [写意国画](https://www.liblib.art/modelinfo/7ac1ed2ee7ca41ad81b7240258ca03f6)
- [水墨晕染](https://www.liblib.art/modelinfo/d849ad85f3ad420a863d533381baec1b)

## 二、通用负面提示词（每张都要带）

```
文字, 书法, 印章, 题款, 落款, 题跋, 签名, 水印, 彩色, 艳丽, 高饱和,
工笔重彩, 照片, 写实, 3D渲染, 现代元素, 边框, 画框, 装裱, 绫边,
人物正面特写, 多余手指, low quality, blurry,
text, calligraphy, signature, seal, stamp, watermark, frame
```

**「文字 / 印章」这两项绝对不能漏**——否则 AI 会在角落"画"出几个篆书似的鬼画符，懂行的一眼看出是假的，比不写字更糟。

## 四、挑图标准（比生成更重要）

拿到 8 张先看四件事，不合格直接淘汰：

| 看什么 | 淘汰条件 |
|---|---|
| **留白** | 画面被填满，没地方写诗 → 淘汰（提示词里的留白方向就是为这个） |
| **有没有鬼画符** | **放大**看角落，有像篆书又不是字的笔画 → 淘汰 |
| **墨色层次** | 整片死黑、没有浓淡过渡 → 淘汰 |
| **风格一致性** | 把 11 首的挑选结果**并排放**，风格跳出来的重做 |

## 五、生成完之后

```bash
# 1. 把挑好的图按上面的文件名放进 _build/art/
#    例如：_build/art/wangui.jpg  _build/art/yuye.jpg ...

# 2. 一行命令压成两档 WebP（会自动覆盖 images/art/ 里的同名文件）
python tools/make-art-webp.py

# 3. 页面上就换好了 —— ART 表按标题查，文件名不变就不用改代码
```

⚠️ **如果新图里有 AI 生成的**，记得在 `ART` 表对应条目的 `credit` 里改成
`AI 生成（通义万相 / LiblibAI 等）`——这是《生成式人工智能服务管理暂行办法》
要求的显著标识，也是该有的诚实。
